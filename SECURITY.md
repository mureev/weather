# Security

## Reporting

Report privately, with GitHub's **Report a vulnerability** button on this
repository's *Security* tab — not in a public issue.

## Scope

Anything by which the phone's data reaches a third party: its address, its
location, its headers or its timezone, leaving by a subresource, a redirect, a
forwarded header, a log line or a route nobody thought of. Keeping those on the
phone and the server is the property this project exists for (`README.md`,
*Privacy, and the ways it leaks*).

Ordinary bugs, a wrong forecast included, are issues rather than reports.

## What to expect

This is a personal instance with one user. There is no bounty and no promised
response time. A fix, once there is one, is live within minutes of reaching
`master`.
