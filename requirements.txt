# Runtime only. Everything here is imported by the app on a normal request
# path; nothing is here "in case".
#
# Lower bounds for humans; `requirements.lock` is what is installed and shipped.
# `make lock` rewrites it, by the command at its top, keeping every pin that
# still satisfies this file. The test tools are `requirements-dev.txt`.
fastapi>=0.115          # routing, DI, the security-header plumbing
uvicorn>=0.30           # ASGI server
httptools>=0.6          # C HTTP parser for uvicorn -- measurable, 2 MB
httpx2[http2]>=2.13     # upstream fetches; [http2] pulls h2, which we use.
                        # The maintained HTTPX (DECISIONS.md §39).
certifi>=2024.2         # the trust anchors http.py loads once -- in place of
                        # httpx2's default, which re-reads the system store
                        # on every new connection (§39)
lxml>=5.2               # the parsers. The one genuinely large dependency, 12 MB

# Deliberately NOT `uvicorn[standard]`. That extra pulls uvloop (14 MB),
# websockets, watchfiles and PyYAML -- 19 MB measured, none of it reachable
# from this app. There are no websockets, nothing reloads in production, no
# YAML is ever parsed, and uvloop optimises an event loop whose time is spent
# waiting on three upstream HTTP requests. Buying 14 MB of resident image to
# speed up the part that was never the bottleneck is the wrong trade for a box
# this small; httptools is kept because it is 2 MB and does help.
